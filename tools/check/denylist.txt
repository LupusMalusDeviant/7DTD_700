# Denylist fuer mod700check anachronisms (Vertrag 04, Abschnitt 3)

# Eine Regel pro Zeile, '*' steht fuer beliebig viele Zeichen, '#' beginnt einen Kommentar.
# Eine Zeile mit '!' am Anfang ist eine Freigabe und schlaegt jedes Verbot.
#
# Geprueft wird NICHT, ob ein Gegenstand existiert, sondern ob ein Spieler ihn ERREICHEN
# kann: ueber ein Rezept, eine Loot-Gruppe, eine Haendlergruppe, eine Quest-Belohnung oder
# die Startausruestung. Gesperrte Gegenstaende bleiben absichtlich in items.xml stehen,
# weil Prefabs und Quests auf sie zeigen (Vertrag 03, Abschnitt 4).
#
# Dieser Stand ist der Anfang, nicht das Ende: die vollstaendige Liste entsteht in WP3.1
# gegen die echten Dateien. Was hier fehlt, faellt dort auf.
#
# WP3.1 hat genau das getan. Der Lauf gegen das echte Data/Config meldete 138 Kennungen,
# und 32 davon waren Fehltreffer dieser Liste, nicht Anachronismen des Spiels:
# Boegen heissen in Vanilla 'gunBow*', Pfeile 'ammoArrow*' - und 'gun*' bzw. 'ammo*' hat
# sie mitgenommen, obwohl P3 und D8 sie ausdruecklich als Inhalt nennen. Das stand hier
# nicht, weil diese Liste vor dem ersten Lauf aus den Feature-Texten geschrieben wurde.
# Die Freigaben im zweiten Block unten sind das Ergebnis (D54, D55, D56).
