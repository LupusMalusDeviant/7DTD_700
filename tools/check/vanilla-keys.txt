# Bewusste Vanilla-Ueberschreibungen in mod/700_90_Sprache/Config/Localization.csv
#
# mod700check localization verlangt fuer jeden Schluessel das Praefix '700_' und meldet
# sonst 'schluessel-ohne-praefix'. Das ist richtig fuer alles, was wir neu erfinden: ein
# eigener Gegenstand mit einem Vanilla-Namen waere ein Namenskonflikt mit Ansage.
#
# Hier stehen die Ausnahmen, und sie sind eine Bauart, kein Loch: wir deuten Vanilla-Dinge
# um, statt sie zu ersetzen. resourceScrapIron bleibt resourceScrapIron - 585 Abwurfzeilen,
# 51 Loot-Eintraege und jedes Rezept zeigen auf diesen Namen -, und der Spieler liest
# "Raseneisenerz". Das geht, weil eine Modlet-Zeile den Vanilla-Schluessel ueberschreibt;
# belegt in docs/rea/findings/WP4-localization-ueberschreibt-vanilla.md (addCsv nimmt im
# Modlet-Zweig Dictionary::set_Item, nicht Add).
#
# JEDE ZEILE HIER IST EINE ENTSCHEIDUNG. Wer einen Schluessel eintraegt, nur damit die
# Pruefung schweigt, hat die Pruefung abgeschaltet und nicht bestanden. Der Grund gehoert
# daneben, und die Liste bleibt kurz genug, dass man sie liest.
