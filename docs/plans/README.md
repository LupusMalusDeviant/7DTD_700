# Pläne

Implementation-Pläne des Projekts. Ein Plan pro Vorhaben, nummeriert `NNNN-slug.md`.

Ein Plan ist **lebend**: er wird nachgezogen, wenn die Realität etwas anderes sagt. Änderungen
bleiben über die Git-Historie nachvollziehbar, alte Zahlen werden nicht stillschweigend
überschrieben.

Jeder Planpunkt trägt eine Marke: `[Claude-prüfbar]` oder `[braucht Nutzer]`. Die prüfbaren
Punkte erledigt Claude vollständig mit Prüfbefehl, für den Rest steht am Ende jedes Plans eine
nummerierte Prüfliste.
